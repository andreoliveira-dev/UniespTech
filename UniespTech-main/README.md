# Uniesp Tech - Sistema de Gestão Acadêmica

## 🚀 Tecnologias
- Java 21
- H2 Database
- Maven
- Docker
- GitHub Actions (CI/CD)
- SLF4J (Logs estruturados)
- Render (Cloud)

## 🩺 Monitoramento
- **Health Check**: `GET http://localhost:8080/health`
- **Logs**: Diretório `logs/app.log`
